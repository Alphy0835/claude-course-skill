# Скил «Курс по теме» для Claude Code

Называешь тему и уровень ученика — получаешь учебный курс одной страницей: программа, уроки с разборами и схемами, проверочные вопросы, практика, тренажёр и словарь.

## Что нужно

- Claude Code с подпиской. Полный курс из 16 уроков — это 5–6 млн токенов и, по оценке, несколько часов работы. В лимит подписки за один заход он может не уложиться — тогда продолжаешь позже, написанное не пропадает.
- Python 3, без дополнительных пакетов.
- Chrome или Edge — чтобы скил сам посмотрел, как выглядит страница. Без них он тоже работает, просто вёрстку не проверит.

## Как поставить

Проще всего — открой Claude Code в папке, где работаешь, и напиши ему:

```
Склонируй https://github.com/Alphy0835/claude-course-skill в папку .claude/skills/course
```

То же самому, в терминале из этой папки:

```
git clone https://github.com/Alphy0835/claude-course-skill.git .claude/skills/course
```

Без git: на странице репозитория кнопка Code → Download ZIP, распакуй, переименуй папку в `course` и положи в `.claude/skills/`.

Должен получиться файл `.claude/skills/course/SKILL.md`. Перезапусти Claude Code — в списке команд появится `/course`.

Чтобы скил был доступен в любой папке, положи его в `.claude/skills/` в домашней папке пользователя. Обновить до свежей версии: `git -C .claude/skills/course pull`.

## Как запускать

1. Сначала только программа — посмотреть, что войдёт в курс (около 0,7 млн токенов):

   ```
   /course <тема>, уровень ноль, только программа
   ```

2. Программа устраивает — дописать уроки:

   ```
   /course продолжи courses/<папка курса>
   ```

3. Упёрся в лимит или чат оборвался — та же команда «продолжи» в новом чате.

Уровень — `ноль`, `новичок`, `практик`, `профи` или своими словами: «бухгалтер, в программировании ноль». От уровня зависит, с чего курс начинается и каким языком написан; заканчивается он одинаково глубоко.

## Какую тему давать

Узкую: один навык, а не профессию целиком.

- Годится: «тестирование API», «юнит-экономика подписочного сервиса», «контекстная реклама в Яндекс Директе».
- Слишком широко: «тестировщик», «маркетолог». Скил назовёт курсы, из которых складывается такая тема, и сделает один из них. Остальные запускаешь сам, по одному.

## Что получится

Папка `courses/<папка курса>/`, в ней `course.html` — открывается двойным щелчком в браузере. Прогресс и ответы на вопросы запоминаются в этом браузере.

## Что не проверено

Скил проверен на одной теме: построена программа на 16 уроков и написан один урок. Полный курс целиком ещё ни разу не прогонялся, поэтому на шагах после первого урока возможны сбои.
